RSTA-030 External Executor Enforcement: Subject -> RNCP Commitment -> Capability -> External Executor -> real HTTP action -> signed External Reality Receipt -> RNCP verifier. The tested boundary must deny missing/mismatched commitment, wrong executor/action/endpoint/payload, invalid signature, and tampered receipt. This proves the tested integration boundary is enforced; arbitrary third-party infrastructure requires an adapter, gateway, SDK, runtime, or equivalent enforcement point.
